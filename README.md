# TWI4x4 CMS + Stock Demo

เว็บเดโม HTML/CSS/JavaScript สำหรับทดลองขั้นตอน CMS ฝ่ายขาย และฝ่ายคลัง บนคอมและมือถือ ไม่ต้อง build หรือติดตั้ง dependency

## ทดลอง

เปิดเว็บไซต์แล้วเริ่มที่ “คู่มือทดลองทุกเคส” เลือกเคสเพื่อสลับฝ่ายและเปิดหน้าที่เกี่ยวข้องให้อัตโนมัติ

| บิล | สถานะ | ใช้ทดลอง |
|---|---|---|
| SO-DEMO-00001 | จ่ายแล้ว | หลายรายการสินค้า พิมพ์บิล ดูประวัติตัดสต๊อก |
| SO-DEMO-00002 | จ่ายแล้ว | ตัวอย่างจ่ายครบ 1 รายการ |
| SO-DEMO-00003 | รอคลังจ่าย | กระดิ่งแจ้งงาน ยอดจอง จ่ายตามบิล |
| SO-DEMO-00004 | รอคลังจ่าย | สินค้าใกล้หมดและยอดพร้อมขาย |
| SO-DEMO-00005 | ฉบับร่าง | ยืนยันเพื่อจอง หรือยกเลิก |
| SO-DEMO-00006 | ยกเลิก | คืนยอดจองโดยไม่ตัดสต๊อก |

มีข้อมูลรับเข้า เบิกออก รับคืน และปรับยอด พร้อม SKU สถานะสินค้าใกล้หมด/หมด และสินค้าฉบับร่าง/เผยแพร่

เพิ่มสินค้า แก้ไข เผยแพร่ เปิดบิลหลายรายการ กรอกราคา จองสินค้า จ่ายตามบิล ส่งออก CSV และพิมพ์ PDF ได้ ทดลอง SKU ซ้ำ เบิกเกินยอด และจองเกินพร้อมขายเพื่อดูการตรวจสอบ

## GitHub Pages

ไฟล์ index.html, style.css, app.js, sales.js, demo-data.js และ .nojekyll อยู่ที่ root ของ repo

1. Push ไป repo `krittanonmss/TWI4x4_demo`
2. Settings → Pages → Source: Deploy from a branch
3. เลือก branch main และโฟลเดอร์ /(root) แล้ว Save
4. รอ Pages deployment สำเร็จ และใช้ URL ที่ GitHub แสดง

คู่มือ GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## เปิดในเครื่อง

```sh
python3 -m http.server 8080
```

เปิด http://localhost:8080

## ตรวจสอบ

```sh
node tests/workflow.cjs
```

ตรวจข้อมูลตัวอย่าง ยอดจองและยอดสต๊อก ประวัติต่อเนื่อง บิลหลายสถานะ แจ้งเตือน ป้องกันจ่ายซ้ำ ยกเลิกคืนจอง ป้องกันสต๊อกติดลบและต่ำกว่ายอดจอง และการรีเซ็ตตัวอย่าง

## ข้อจำกัด

ข้อมูลทั้งหมดเป็นข้อมูลสมมติ เก็บเฉพาะ localStorage ของเบราว์เซอร์ ไม่แชร์ข้ามเครื่องหรือซิงก์หลายผู้ใช้ การสลับฝ่ายเป็นสิทธิ์จำลอง ไม่มี backend หรือ authentication จริง บิลเป็นใบสั่งขายเดโม ไม่ใช่ใบเสร็จ/ใบกำกับภาษี ไม่มีรับชำระเงิน คำนวณภาษี จ่ายบางส่วน หรือคืนตามบิล

บิลจ่ายแล้วหมายถึงจบขั้นตอนคลัง ไม่ได้หมายถึงรับเงินแล้ว

เมื่อเปิดซ้ำ ข้อมูลที่ทดลองจะยังอยู่ หากต้องการชุดตัวอย่างครบใหม่ให้กด “โหลดชุดตัวอย่างเริ่มต้น” และยืนยันก่อนแทนข้อมูล

ตรวจตรรกะและโครงสร้างไฟล์แล้ว ยังไม่ได้ตรวจการแสดงผลผ่านเบราว์เซอร์อัตโนมัติเนื่องจากข้อจำกัดของสภาพแวดล้อม
